# 2. What is Azure Files?

* SMB

SMB = Server Message Block

Used by:

* Windows
* Linux
* macOS

SMB allows multiple users and VMs to access the same files over the network.

# 6. Storage Security

This is where your video becomes different from many beginner tutorials.

---

## Storage Access Keys

Each Storage Account has:

* Key1
* Key2

Example:

```
Storage Account

Key1

Key2
```

* Full access
* Rotate keys regularly
* Don't hard-code keys in applications

---

## Shared Access Signature (SAS)

Instead of giving full access:

Create a SAS Token.

Example:

```
Read Only

Expires in 24 Hours
```

Advantages:

* Temporary access
* Limited permissions
* More secure than sharing account keys

---

## Comparison

| Storage Access Keys  | SAS Token                  |
| -------------------- | -------------------------- |
| Full access          | Limited access             |
| Long-term            | Temporary                  |
| Less secure to share | Safer for delegated access |

# Step 4

Mount on Linux VM

Open:

Azure Portal

↓

Storage Account

↓

File Share

↓

Connect

Choose:

Linux

Azure generates the mount command.

Install the CIFS utilities (if needed):

```bash
sudo apt update
sudo apt install cifs-utils -y
```

Create a mount point:

```bash
sudo mkdir /mnt/azurefiles
```

Mount the file share (use the command generated by Azure Portal, replacing placeholders with your own values):

```bash
sudo mount -t cifs //<storage-account>.file.core.windows.net/<share-name> /mnt/azurefiles \
-o vers=3.0,username=<storage-account>,password=<storage-account-key>,dir_mode=0777,file_mode=0777,serverino
```

Verify:

```bash
df -h
```

List files:

```bash
ls /mnt/azurefiles
```

Create a test file:

```bash
echo "Azure Files Demo" > /mnt/azurefiles/demo.txt
```

Go back to Azure Portal.

Refresh.

Show:

```
demo.txt
```

This is the "wow" moment.

# Step 7

Azure CLI Demo

Login:

```bash
az login
```

Create a file share:

```bash
az storage share-rm create \
  --resource-group azure30days-rg \
  --storage-account mystorageaccount12345 \
  --name sharedfiles
```

List file shares:

```bash
az storage share-rm list \
  --resource-group azure30days-rg \
  --storage-account mystorageaccount12345 \
  --output table
```

# Hands on: Access Keys & SAS Token 

### 1. Set your variables

Using your example:

```bash
export STORAGE_ACCOUNT="rajiv2026"
export STORAGE_KEY="YOUR_STORAGE_ACCOUNT_ACCESS_KEY"
export CONTAINER="images"
export BLOB="cat.jpg"
```

### 2. Test access to your container

```bash
az storage blob list \
  --account-name "$STORAGE_ACCOUNT" \
  --account-key "$STORAGE_KEY" \
  --container-name "$CONTAINER" \
  --output table
```

You should get:

```text
Name
----------------
cat.jpg
```

### 4. Download the image to WSL

```bash
az storage blob download \
  --account-name "$STORAGE_ACCOUNT" \
  --account-key "$STORAGE_KEY" \
  --container-name "$CONTAINER" \
  --name "$BLOB" \
  --file "./cat.jpg"
```
