# **Azure Functions Hands-On: Automatically Process Uploaded Files**

Python

Azure Blob Storage Trigger

In this demo we will understand three important Azure services working together:

- **Azure Storage Account:** Stores uploaded files.
- **Azure Function:** Automatically executes Python code when a file is uploaded.
- **Azure Storage Account (destination):** Stores the file information generated by the function.

## **1. What are we going to build?**

Imagine that a user uploads a PDF, JPG, PNG, or TXT file to Azure Storage.

As soon as the file is uploaded, an Azure Function automatically triggers and collects:

1. File name
2. File extension/type
3. File size
4. MIME/content type
5. Upload timestamp

The function then creates a JSON file containing this information and uploads that JSON file into another Azure Storage container.


### **Architecture of our project**

**Step 1: User uploads a file**

PDF / JPG / PNG / TXT

**Step 2: Source Azure Storage**

uploads container

Stores the original uploaded file

Blob Trigger automatically fires

**Step 3: Azure Function**

Executes Python code and extracts file metadata

**Step 4: Destination Azure Storage**

file-metadata container

Stores generated JSON files

We are not manually executing the Python function. The Blob Trigger automatically invokes it when a new blob is uploaded.


## **2. What will the final result look like?**

Suppose you upload:

`AWS-Tutorial.pdf`

The Azure Function will automatically generate:

`AWS-Tutorial.pdf.metadata.json`

Example JSON:

```
{
  "file_name": "AWS-Tutorial.pdf",
  "file_extension": ".pdf",
  "file_type": "application/pdf",
  "file_size_bytes": 204800,
  "file_size_kb": 200.0,
  "source_blob": "uploads/AWS-Tutorial.pdf"
}
```

We will see the original PDF in the first storage account and the generated JSON in the second storage account.

## **3. What Azure resources do we need?**

For a better understanding, we are using two Storage Accounts.

| Azure resource    | Name (example)              | Purpose                 |
| ----------------- | --------------------------- | ----------------------- |
| Storage Account 1 | `stdevopsupload01`          | Stores uploaded files   |
| Storage Account 2 | `stdevopsprocess01`         | Stores JSON metadata    |
| Container 1       | `uploads`                   | Receives original files |
| Container 2       | `file-metadata`             | Receives generated JSON |
| Function App      | `func-devops-fileprocessor` | Executes Python code    |

All storage account names must be globally unique, lowercase, and 3–24 characters. Adjust the example names if unavailable.

The second Storage Account will also be used as the Function App's host storage for this beginner lab. This keeps the architecture simple. In production, consider separating the Function App's host storage from application output storage.

## **9. Write the Python code**
Open `function_app.py` in VS Code and replace its contents with the following code.
```sh
import azure.functions as func
import logging
import os
import json
import mimetypes

from datetime import datetime, timezone
from pathlib import PurePosixPath
from azure.storage.blob import BlobServiceClient
from azure.core.exceptions import ResourceExistsError

app = func.FunctionApp()

@app.blob_trigger(
    arg_name="myblob",
    path="uploads/{name}",
    connection="SOURCE_STORAGE_CONNECTION"
)
def FileUploadTrigger(myblob: func.InputStream):

    logging.info("Azure Blob Trigger started!")

    # Get uploaded file information
    source_blob_name = myblob.name
    file_name = PurePosixPath(source_blob_name).name
    file_size = myblob.length

    # Detect file extension and MIME type
    file_extension = PurePosixPath(file_name).suffix.lower()

    content_type, _ = mimetypes.guess_type(file_name)

    if content_type is None:
        content_type = "application/octet-stream"

    # Create metadata JSON
    metadata = {
        "file_name": file_name,
        "file_extension": file_extension,
        "file_type": content_type,
        "file_size_bytes": file_size,
        "file_size_kb": round(file_size / 1024, 2),
        "source_blob": source_blob_name,
        "processed_at": datetime.now(timezone.utc).isoformat()
    }

    # Connect to destination Storage Account
    destination_connection = os.environ[
        "DEST_STORAGE_CONNECTION"
    ]

    blob_service_client = BlobServiceClient.from_connection_string(
        destination_connection
    )

    # Get destination container
    container_client = blob_service_client.get_container_client(
        "file-metadata"
    )

    # Create container if it does not exist
    try:
        container_client.create_container()
    except ResourceExistsError:
        pass

    # Generate JSON filename
    metadata_file_name = (
        source_blob_name.replace("/", "_") + ".metadata.json"
    )

    # Upload JSON metadata to destination storage
    destination_blob = container_client.get_blob_client(
        metadata_file_name
    )

    destination_blob.upload_blob(
        json.dumps(metadata, indent=4),
        overwrite=True,
        content_type="application/json"
    )

    logging.info(
        f"Metadata uploaded successfully: {metadata_file_name}"
    )

    logging.info(f"File name: {file_name}")
    logging.info(f"File type: {content_type}")
    logging.info(f"File size: {file_size} bytes")
```

### **Understand the important code**

| Code                     | What it does                                       |
| ------------------------ | -------------------------------------------------- |
| `@app.blob_trigger`      | Automatically triggers when a blob is detected.    |
| `path="uploads/{name}"`  | Monitors the uploads container.                    |
| `myblob.name`            | Gets the uploaded blob's name.                     |
| `myblob.length`          | Gets its size in bytes.                            |
| `mimetypes.guess_type()` | Determines the likely MIME type from its filename. |
| `BlobServiceClient`      | Connects to Azure Blob Storage.                    |
| `upload_blob()`          | Uploads the generated JSON file.                   |
